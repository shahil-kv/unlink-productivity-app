# Unlink — getunlink.com

Landing page and email backend for [Unlink](https://getunlink.com), the Android app that surgically blocks YouTube Shorts and Instagram Reels without touching the rest of the apps.

Built with Next.js 16 (App Router), React 19, Tailwind v4, deployed on Vercel.

---

## What is Unlink?

Most screen-time apps make you choose: block YouTube entirely, or use it freely. Unlink does neither.

**Surgical Mode** detects when you open YouTube Shorts or Instagram Reels specifically — and blocks only that feed, letting you use Search, Subscriptions, and DMs normally.

Key facts:
- Zero login. No account, no Google sign-in, no email required to use the app.
- Zero data collection. Block list, session history, usage stats — all stored on-device, never uploaded.
- Open source. The full Android app source is public.
- No ads, no analytics SDK, no Firebase.

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

No environment variables are required for the UI. The waitlist API silently no-ops in dev without a key configured.

### Environment variables (production only)

| Variable | Where | Purpose |
|---|---|---|
| `RESEND_API_KEY` | Vercel project settings | Sends waitlist confirmation emails and Mom Test verification emails |

Set this in your Vercel project dashboard under Settings → Environment Variables. Never commit it.

## Email API

The landing page exposes one API route:

**`POST /api/waitlist`**

Body: `{ "email": "user@example.com" }`

On success, it fires two emails in parallel:
1. Developer notification to `mshahilkv@gmail.com`
2. Waitlist confirmation to the submitted address (includes GitHub + Telegram links)

The app's Mom Test feature sends verification emails through a separate endpoint at `POST /api/send-email` (deployed as a Vercel Edge Function in the `Landing-page/` directory). The API key lives server-side — it is never in the APK.

## Android app

The Android source is in the main `Unlink-Application` monorepo.

Key architecture decisions:
- **Accessibility Service** — the only reliable way to detect the foreground app in real time on Android. Processes everything on-device; zero data leaves the phone.
- **Surgical Mode** — reads resource IDs (`com.google.android.youtube:id/reel_recycler`, `com.instagram.android:id/clips_viewer_view_pager`) to detect Shorts/Reels feeds specifically.
- **Strict Mode** — uses Device Administrator permission (user-granted, user-revocable) to prevent uninstall during an active session.
- **Mom Test** — trusted contact receives a one-time code when you try to exit early; code goes through a server-side proxy, email is never stored.
